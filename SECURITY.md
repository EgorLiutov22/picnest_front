## 🛡️ Рекомендуемые практики безопасности

### Хранение токенов

> ⚠️ **Важно**: В текущей реализации токены хранятся в localStorage, что может быть небезопасно для production.

**Рекомендация**: Для production рассмотрите использование HTTP-only cookies:

```typescript
// Вместо localStorage
localStorage.setItem('accessToken', token);

// Используйте HTTP-only cookie через API
await api.post('/login', { email, password });
// Сервер устанавливает HttpOnly cookie
```

### CORS и CSRF защита

Убедитесь, что бэкенд настроен правильно:

- Включите CORS только для доверенных origins
- Используйте CSRF tokens для форм
- Настройте правильные заголовки безопасности

### Валидация данных

Все входные данные проходят валидацию через Zod схемы. Не отключайте эту проверку!

```typescript
// ✅ Всегда валидируйте входные данные
const validatedData = LoginRequestSchema.parse(credentials);

// ❌ Никогда не пропускайте валидацию
await api.login(credentials); // Без проверки!
```

## 🔒 Безопасность токенов JWT

### Refresh Token Rotation

Реализована rotation refresh токенов для защиты от кражи сессии.

**Как это работает:**

1. При каждом запросе к API проверяется access token
2. Если access token истек, автоматически обновляется через refresh token
3. После успешного обновления:
   - Генерируется новый refresh token (старый аннулируется)
   - Это предотвращает повторное использование украденного токена

### Хранение токенов в памяти

Для повышенной безопасности рассмотрите хранение токенов только в памяти приложения:

```typescript
// Хранилище токенов в памяти (не localStorage)
const tokenStore = {
  accessToken: null as string | null,
  
  set(token: string) {
    this.accessToken = token;
  },
  
  get(): string | null {
    return this.accessToken;
  }
};
```

## 📋 Security Headers

Рекомендуемые заголовки для бэкенда:

```
Content-Security-Policy: default-src 'self'; script-src 'self'
X-Content-Type-Options: nosniff
X-Frame-Options: DENY
X-XSS-Protection: 1; mode=block
Strict-Transport-Security: max-age=31536000; includeSubDomains
```
