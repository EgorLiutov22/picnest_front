# Changelog

Все значимые изменения этого проекта будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) и следует [Conventional Commits](https://www.conventionalcommits.org/).

## [Unreleased]

### Добавлено

- Базовая конфигурация проекта (Vite, React 18+, TypeScript)
- Система аутентификации с JWT токенами
- Компонент ProtectedRoute с RBAC защитой
- Zustand стор для управления состоянием авторизации
- Валидация данных через Zod схемы

### Изменения

- Конфигурация Axios с интерсепторами авторизации
- Автоматическое обновление токенов через refresh token
- Защита маршрутов по ролям пользователей

- Примеры защищённых маршрутов для разных ролей пользователей
